# CPU 스케줄링 시뮬레이터

아직 명세를 쓰기 전이다. 기본기(특히 03, 06, 09, 15장)를 끝낸 뒤 `SPEC.md`와 뼈대 코드를 만든다.

시간을 사이클 단위로 흘려 보내면서 프로세스 생성, IO 요청, IO 완료, 종료 같은 이벤트를 처리하는 시뮬레이터를 만든다. 스케줄링 알고리즘(FIFO, RR, SJF, SRTN, Guaranteed, MLFQ 등)을 갈아 끼우면서 같은 워크로드에서 결과가 어떻게 달라지는지 비교하는 게 목표다. 한 사이클에 이벤트가 여러 개 겹칠 때 무엇부터 처리하는지, 기준값이 같으면 누가 먼저인지 같은 규칙은 명세에서 정한다.

워크로드(도착 간격, 수행 시간, IO 요청 간격, IO 처리 시간)는 시드를 받아서 만들고, 결과는 프로세스별 통계와 전체 통계로 출력한다.

시뮬레이션 루프, 워크로드 생성기, 통계 출력은 뼈대로 준비해 두고, 알고리즘별 스케줄러와 ready queue, 상태 전환은 직접 구현한다. 검증은 `./check go project cpu-scheduling`으로 한다. 고정된 시드로 돌린 결과를 golden 파일과 비교하고, 상태 전환 규칙이 지켜지는지 테스트한다.

관련 섹션: 03(링 버퍼 큐), 06(인터페이스), 09(안정 우선순위 큐), 15(결정적 난수, golden 테스트)
