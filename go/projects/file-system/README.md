# 단순 파일 시스템

아직 명세를 쓰기 전이다. 기본기(특히 05, 06, 07, 08장)를 끝낸 뒤 `SPEC.md`와 뼈대 코드를 만든다.

디스크 이미지 파일을 블록 단위로 읽고 쓰는 작은 파일 시스템과, 그 위에서 도는 셸을 만든다. 디스크에는 superblock, inode, 블록 비트맵, 디렉터리 엔트리가 들어가고, 셸은 mount, ls, cd, mkdir, rmdir, touch, rm, mv, cpin, cpout을 지원한다.

디스크 이미지는 저장소에 넣지 않고, 테스트할 때마다 `mkfs`로 새로 만든다.

블록 디바이스 계층, 셸 입력 파서, 디스크 덤프 도구는 뼈대로 준비해 두고, 경로 탐색, 디렉터리 조작, 파일 읽기/쓰기, 블록 할당과 해제는 직접 구현한다. 검증은 `./check go project file-system`으로 한다. 명령 스크립트를 실행한 결과를 golden과 비교하고, 디스크 구조가 깨지지 않았는지(fsck)도 검사한다.

관련 섹션: 05(바이너리 인코딩, 비트맵), 06(BlockDevice 인터페이스와 테스트 대역), 07(에러 처리), 08(ReadAt/WriteAt 블록 I/O)
