# 가상 메모리 시뮬레이터

아직 명세를 쓰기 전이다. 기본기(특히 05, 08, 09, 11장)를 끝낸 뒤 `SPEC.md`와 뼈대 코드를 만든다.

여러 프로세스의 메모리 접근 기록(trace: 가상 주소와 읽기/쓰기 여부)을 번갈아 읽으면서 주소 변환과 페이지 교체를 시뮬레이션한다. 페이지 테이블은 1단계, 2단계, 역(inverted) 세 가지를 만들고, 교체 정책은 FIFO와 LRU를 구현해서 page fault와 hit 통계를 비교한다.

큰 trace 파일은 저장소에 넣지 않는다. 대신 시드로 trace를 만들어 내는 생성기(반복 루프, 무작위 접근, 작업 집합 같은 패턴)와 손으로 계산해 볼 수 있는 작은 샘플만 둔다.

trace 생성기와 리더, 통계 출력은 뼈대로 준비해 두고, 페이지 테이블 세 종류와 교체 정책, 물리 프레임 관리는 직접 구현한다. 검증은 `./check go project virtual-memory`로 한다. 고정 시드 trace의 통계를 golden과 비교하고, 작은 trace는 손으로 계산한 값과 맞춰 본다.

관련 섹션: 05(비트 연산으로 주소 쪼개기), 08(여러 reader 번갈아 읽기), 09(LRU), 02와 11(포인터 없는 페이지 테이블 설계)
